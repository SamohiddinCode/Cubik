# Planner — привычки

## Назначение

«Привычки» превращают повторяющиеся действия в измеримый ритм. Привычка остаётся общей сущностью `Task` с `habit: true`, поэтому её название, список, описание, цель и повторение доступны в Today, Calendar и общем Task Inspector. Отдельный журнал хранит только факты выполнения по датам.

## Реализовано

- список всех задач с признаком привычки;
- создание привычки с частотой каждый день, раз в неделю или раз в месяц;
- привязка новой привычки к пользовательскому списку;
- отметка и отмена выполнения текущего периода;
- корректная логика периода: день, календарная неделя с понедельника или месяц;
- текущая серия и регулярность за 7 дней, 4 недели или 3 месяца;
- календарная полоса последних семи дней для каждой привычки;
- недельный график фактических отметок;
- фильтры «Все», «Осталось» и «Готово»;
- поиск по названию, описанию и меткам через глобальный поиск Planner;
- открытие общего Task Inspector для редактирования привычки;
- адаптивная компоновка и пустые состояния;
- сохранение журнала после перезагрузки.

## Данные

Привычка хранится в основном Planner repository как `Task`:

- `habit: true`;
- `recurrence: daily | weekly | monthly`;
- остальные поля Task используются без дублирования.

Журнал отметок хранится под ключом `cubik.planner.habits.v1`:

```text
checkins[taskId] = ["2026-09-05", "2026-09-06"]
```

Нормализатор удаляет повреждённые даты, дубликаты и ограничивает историю одной привычки последними 500 отметками.

## Карта исходников

- `src/features/planner/habit-model.ts` — периоды, отметки, серии, регулярность и нормализация;
- `src/features/planner/components/habit-tracker.tsx` — экран и взаимодействия;
- `src/features/planner/components/habit-tracker.module.css` — визуальная система и responsive;
- `src/features/planner/use-planner.ts` — создание общей Task с `habit: true`;
- `src/features/planner/today-planner-page.tsx` — навигация и подключение модуля;
- `scripts/check-habits.mjs` — детерминированные проверки модели.

## Ограничения локального MVP

- журнал локален одному браузеру и пока не участвует в общем Undo/Redo;
- нет произвольных расписаний по дням недели и нескольких повторов в день;
- нет напоминаний, совместных привычек и синхронизации устройств;
- наблюдение на экране детерминированное, а не ответ AI;
- после Auth + PostgreSQL журнал нужно перенести в серверный repository, не меняя UI-контракт.

## Проверка

```bash
pnpm test:habits
pnpm typecheck
pnpm lint
pnpm build
```

Ручной сценарий: открыть «Привычки», отметить существующую привычку, проверить счётчик и серию, создать новую привычку, обновить страницу и убедиться, что данные восстановились; затем открыть её Task Inspector и удалить тестовую запись.
