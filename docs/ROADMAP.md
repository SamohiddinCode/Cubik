### Planner foundation — уже реализовано

- типизированная сущность `Task` с датой, временем, длительностью, приоритетом, списком, тегами, описанием, повторением, целью, подзадачами и метаданными вложений;
- пользовательская сущность `TaskList` с CRUD и цветами;
- единый Planner state v2 (`tasks + lists`) в `localStorage`;
- автоматическая миграция данных из `cubik.planner.tasks.v1` без удаления старых задач;
- безопасная нормализация повреждённых локальных записей;
- единый `usePlanner` service/hook вместо прямого управления данными из UI;
- создание, редактирование, завершение и удаление задач;
- создание, переименование и удаление списков без удаления связанных задач;
- сохранение после перезагрузки браузера;
- Today / Tomorrow / Next 7 Days / Inbox / All;
- фильтрация по пользовательским спискам;
- поиск по названию, описанию и тегам;
- сортировка по времени, приоритету и дате создания;
- группировка задач по списку, приоритету и статусу;
- подсказки существующих тегов в TaskInspector;
- динамический Summary для прогресса, времени и приоритетных задач;
- расписание Today строится из реальных временных полей задач;
- клиентский clock без SSR hydration mismatch для даты, приветствия и линии текущего времени;
- клавиатурный выбор задачи, `N` для quick add и `⌘/Ctrl+K` для поиска;
- отдельный TaskInspector с подзадачами и подготовленной моделью вложений;
- responsive ListManager;
- CI проверяет install, typecheck, lint и production build;
- AI UI не имитирует реальные вызовы: серверные действия остаются запланированы на фазу 3.
