# Planner — матрица Эйзенхауэра

## Назначение

Матрица — второй рабочий вид тех же задач Planner. Она не создаёт отдельные записи и не копирует данные: квадрант определяется полем `Task.priority`, поэтому изменение сразу отражается в Today, списках, календаре и карточке задачи.

## Связь квадрантов с данными

| Приоритет | Квадрант | Действие |
|---|---|---|
| `P1` | Важно и срочно | Сделать сейчас |
| `P2` | Важно, не срочно | Запланировать |
| `P3` | Срочно, не важно | Делегировать |
| `P4` | Не срочно и не важно | Сократить |

Это продуктовое решение для текущего MVP. Если позже понадобятся независимые оси `important` и `urgent`, потребуется миграция модели, storage и фильтров.

## Реализовано

- четыре адаптивных квадранта с количеством задач;
- общий поиск из topbar;
- фильтры по сроку и пользовательскому списку;
- сортировка вручную, по сроку и названию;
- отдельный переключатель завершённых задач;
- быстрое добавление прямо в нужный квадрант;
- drag-and-drop между квадрантами;
- доступная альтернатива drag-and-drop через select на карточке;
- завершение задачи и открытие общего Task Inspector;
- краткая статистика по открытым, важным и срочным задачам;
- одна колонка на мобильных экранах.

## Карта исходников

- `src/features/planner/components/eisenhower-matrix.tsx` — экран и взаимодействия;
- `src/features/planner/components/eisenhower-matrix.module.css` — сетка, карточки и responsive;
- `src/features/planner/eisenhower-model.ts` — конфигурация квадрантов, фильтрация и сортировка;
- `src/features/planner/today-planner-page.tsx` — навигация и подключение к общему Planner service;
- `scripts/check-eisenhower.mjs` — детерминированные проверки модели.

## Ограничения локального MVP

- ручной порядок берётся из общего `Task.order`; отдельного порядка внутри квадранта нет;
- делегирование пока означает решение пользователя, но не отправку задачи другому человеку;
- AI-рекомендации по приоритету появятся только после server gateway и flow `preview → confirm → apply → undo`;
- синхронизация между устройствами появится после Auth и PostgreSQL.
